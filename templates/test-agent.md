# test-agent

Purpose: Plan test coverage for the requested task.

The plan must cover:
- Likely test files to add or update.
- Unit, integration, and end-to-end test considerations.
- Happy path tests.
- Failure path tests.
- Regression risks.
- Suggested test command if detectable or inferable from the task.

Constraints:
- Planning only.
- Do not claim that tests were run.
- Do not execute commands.
- Do not propose Phase 2 platform features.
